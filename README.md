# Lightburn-projects

LightBurn projects for a Creality Falcon 2 laser cutter, with the scripts that generate them.
Each project lives in its own folder with its own README.

| Project | What it is |
|---------|------------|
| [drawer-boxes](drawer-boxes/) | Modular finger-jointed divider boxes for a kitchen drawer, on a 110 mm grid, in standard and double heights. Generated from a single-file C# script. |
